# AndyGomez--ProyectoFinal

## Matricula: 1000-6215

## Descripcion: 

El proyecto consiste en un videojuego basado en flappy bird con la herramienta javaFX.

Incluye deteccion de colisiones con el suelo, el techo y los obstaculos.

Simulacion de obstaculos los cuales se desplazan para que el personaje los evite y se generan con una altura aleatoria.

Marcador en tiempo real que detecta cuando el personaje supera un obstaculo.

Simulacion de gravedad que provoca que el personaje decienda cada vez mas rapido.

movimiento del personaje el cual puede volar para evitar las tuberias presionando espacio o con el clic izquierdo del mouse.

Deteccion de gameover, el programa comprueba que el personaje ah chocado con un obstaculo y lanza la pantalla de game over.

Rnking de puntuaciones, en la pantalla de game over se incluye el ranking de las puntuaciones de mayor a menor.

Navegacion entre las diferentes pantallas de inicio, game over y de la partida.
